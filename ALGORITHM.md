# Алгоритм игры «Виселица» (текстом)

**НАЧАЛО**

## 1. Подготовка

1. Открыть окно игры 900×550 и включить 60 кадров в секунду.
   ```cpp
   InitWindow(900, 550, "Hangman");
   SetTargetFPS(60);
   ```
2. Подготовить список из 15 слов и включить случайный выбор.
   ```cpp
   vector<string> words = { "programming", "computer", ... };
   srand((unsigned)time(0));
   ```
3. Начать новую игру (см. раздел «Подпрограмма: новая игра»).
   ```cpp
   NewGame(word, hidden, usedLetters, errors, gameOver, win, words);
   ```

## 2. Главный цикл (повторяется, пока окно не закрыто)

```cpp
while (!WindowShouldClose()) { ... }
```

### 2.1. Перезапуск

4. **Если** игра окончена **и** нажата клавиша R:
   - начать новую игру;
   - очистить очередь нажатых клавиш, чтобы буква R не попала в новую игру.
   ```cpp
   if (gameOver && IsKeyPressed(KEY_R)) {
       NewGame(...);
       ClearInputBuffer();
   }
   ```

### 2.2. Ввод букв (только если игра ещё идёт)

5. **Если** игра не окончена, взять первую нажатую клавишу из очереди.
   ```cpp
   int key = GetCharPressed();
   ```
6. **Пока** в очереди есть клавиши (`key > 0`), для каждой:
   1. **Если** это не английская буква (A–Z, a–z) — пропустить и перейти к пункту 6.7.
      ```cpp
      if ((key >= 'A' && key <= 'Z') || (key >= 'a' && key <= 'z'))
      ```
   2. Сделать букву строчной.
      ```cpp
      char letter = (char)tolower(key);
      ```
   3. **Если** эту букву уже называли — пропустить и перейти к пункту 6.7.
      ```cpp
      if (usedLetters.find(letter) == string::npos)
      ```
   4. Запомнить букву в списке названных и считать, что в слове её нет.
      ```cpp
      usedLetters += letter;
      usedLetters += " ";
      bool found = false;
      ```
   5. Пройти по всем позициям слова. **Если** буква на позиции совпала с названной — открыть её и отметить, что буква найдена.
      ```cpp
      for (size_t i = 0; i < word.length(); i++) {
          if (word[i] == letter) { hidden[i] = letter; found = true; }
      }
      ```
   6. **Если** буква не найдена:
      - добавить одну ошибку;
      - **если** ошибок стало 6 или больше — игра окончена, проигрыш.
      ```cpp
      if (!found) {
          errors++;
          if (errors >= 6) { gameOver = true; win = false; }
      }
      ```
      Затем **если** все буквы слова открыты — игра окончена, победа.
      ```cpp
      if (hidden == word) { gameOver = true; win = true; }
      ```
   7. Взять следующую нажатую клавишу и вернуться к началу пункта 6.
      ```cpp
      key = GetCharPressed();
      ```

### 2.3. Рисование кадра (каждый проход цикла)

7. Начать рисование и залить фон белым.
   ```cpp
   BeginDrawing();
   ClearBackground(RAYWHITE);
   ```
8. Написать заголовок «HANGMAN».
9. Нарисовать виселицу и человечка по числу ошибок (см. раздел «Подпрограмма: рисование виселицы»).
   ```cpp
   DrawHangman(errors);
   ```
10. Показать слово с пропусками, названные буквы и число ошибок «N / 6».
11. **Если** игра окончена:
    - **если** победа — написать «YOU WIN!»;
    - **иначе** — написать «YOU LOSE» и показать загаданное слово;
    - написать подсказку «Press R to play again».
12. **Иначе** написать подсказку «Type letters on the keyboard».
13. Закончить рисование кадра.
    ```cpp
    EndDrawing();
    ```
14. Вернуться к началу главного цикла (раздел 2).

## 3. Завершение

15. Окно закрыто — закрыть окно игры и выйти из программы.
    ```cpp
    CloseWindow();
    return 0;
    ```

## Подпрограмма: новая игра

1. Выбрать случайное слово из списка.
   ```cpp
   word = words[rand() % words.size()];
   ```
2. Закрыть все буквы слова чёрточками.
   ```cpp
   hidden.assign(word.length(), '_');
   ```
3. Очистить список названных букв.
4. Обнулить число ошибок.
5. Отметить: игра идёт, победы пока нет.
   ```cpp
   usedLetters.clear(); errors = 0; gameOver = false; win = false;
   ```

## Подпрограмма: очистка очереди клавиш

1. **Пока** в очереди есть нажатая клавиша — взять её и выбросить.
   ```cpp
   while (GetCharPressed() > 0) { }
   ```

## Подпрограмма: рисование виселицы

1. Нарисовать столб, перекладину и верёвку (всегда).
2. **Если** ошибок хотя бы 1 — нарисовать голову.
3. **Если** хотя бы 2 — туловище.
4. **Если** хотя бы 3 — левую руку.
5. **Если** хотя бы 4 — правую руку.
6. **Если** хотя бы 5 — левую ногу.
7. **Если** 6 — правую ногу.
   ```cpp
   if (errors >= 1) DrawCircleLines(250, 160, 30, BLACK);
   if (errors >= 2) DrawLine(250, 190, 250, 290, BLACK);
   ```
